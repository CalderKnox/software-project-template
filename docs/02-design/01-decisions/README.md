# Design Decisions

Design-level decisions and trade-off notes that shape a component or feature
but do not warrant a formal ADR.

Formal, long-lived decisions with governance weight belong in
[01-adrs/](../../01-adrs/); record them there and link from here.

Use this directory for a component-local implementation trade-off. Use an ADR
when the decision is cross-cutting, difficult to reverse, or a durable
compatibility, security, or operational commitment. Promote the note rather
than silently rewriting it.
